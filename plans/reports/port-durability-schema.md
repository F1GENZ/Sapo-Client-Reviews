## Deliberately not ported

AI/highlights/credits, Super Heavy, outbound webhooks, BullMQ/worker role, Haravan token refresh and tier heuristics (out of scope by decision). Billing code untouched. M10 outside the sweeps above: Sapo has no other sweeps.

## Open risks / needs from others

- Public controllers should call `ReviewService.isStoreServing` / rely on the empty answers; they currently still shape responses themselves (owned by another agent). Q&A/Reviews controllers keep working unchanged.
- `storefront/snippets/theme/f1genz-sapo-widget.bwt` (not mine) still reads `product.metafields.reviews.public_summary` with `json_parse`: wrong namespace (app writes `f1genz_reviews`) and an unverified filter. Switch it to the `f1genz_reviews.rating_*` scalars or include `f1genz-product-schema`.
- Webhook header names / signature secret remain unverified; the sweep replays from stored payload so it does not depend on them.
- Sapo metafield value size cap is still unmeasured; the three values are each ~100 bytes or less.
- `public-media.controller.ts` / `media.service.ts` compile errors seen mid-run belong to other agents.
